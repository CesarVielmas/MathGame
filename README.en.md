## ✨ Project Description

<!--proyect_content_description-->
**Numblers** is an educational math game developed in **React Native**, powered by a custom **game engine**, and containerized with **Docker** for modular deployment and scalability. The game is designed to teach math concepts through interactive levels, animated characters, and themed maps.

It blends playful mechanics with progressive math challenges, allowing players to learn while exploring visual worlds, solving problems, and unlocking educational content.

---

<!--proyect_subtitle_objective-->
## 🎯 Project Objective

<!--proyect_content_objective-->
The main goal of **Numblers** is to **motivate math learning** through a fun, visual, and engaging experience. The game targets elementary and middle school students, with levels tailored to different skill levels and themes that reinforce logic, mental math, and problem-solving.

By using modern technologies like React Native and Docker, Numblers is designed to be cross-platform, scalable, and easy to maintain across educational environments.

---

<!--proyect_subtitle_functionality-->
## 🧩 Core Functionality

<!--proyect_content_functionality-->
The game is divided into five key sections:

1. **Intro animation:** A dynamic opening sequence introducing the Numblers universe with music, characters, and atmosphere.  
2. **Main menu:** Overview of available levels, character selection, music settings, and access to progress stats.  
3. **Level maps:** Themed worlds where players navigate to find math challenges.  
4. **Level selection screen:** Interface for choosing specific math challenges within each map.  
5. **Active level gameplay:** Real-time interaction with the environment, solving exercises, collecting items, and progressing through platform-style stages.

## 🖥️ Design and User Experience

<!--proyect_content_designUX-->
Numblers features a colorful, intuitive interface designed for young learners. Visual elements are crafted to support learning without distraction. Characters are smoothly animated, maps are musically themed, and challenges are presented clearly and progressively.

The responsive design ensures compatibility across devices—from classroom tablets to personal smartphones.

---

<!--proyect_subtitle_architecture-->
## 🏗️ Technical Architecture

<!--proyect_content_architecture-->
Numblers is built on a modular and scalable architecture:

- **Mobile frontend:** Developed in React Native with a custom game engine for gameplay logic.  
- **Docker containers:** Used to encapsulate services, simplify deployment, and maintain consistent environments.  
- **Scene management:** Navigation between screens using internal routing and state control.  
- **Local persistence:** Stores progress, stats, and settings using device storage.  
- **Planned backend:** Future integration for cloud sync, user profiles, and educational analytics.
